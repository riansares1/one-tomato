# One Tomato 🍅

Planificador semanal de comidas para una persona (batch cooking), como PWA para iPhone.

- Stack: Vite + React + TypeScript + Tailwind.
- Sin backend: los datos se guardan en el propio iPhone (IndexedDB).
- Publicada en Vercel.

## Comandos

```bash
npm install     # instalar dependencias
npm run dev     # abrir en modo desarrollo
npm run build   # generar la versión final (carpeta dist)
```
